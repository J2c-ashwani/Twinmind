# Companion campaign artwork

Three original generated keyframes, created with the built-in image_gen tool on 13 November 2026:

- `night-chat.png`: younger adult, ordinary midnight conversation.
- `life-coach.png`: middle-aged parent, a moment after a busy family day.
- `everyday-joy.png`: older adult, lighter chat and an everyday smile.

The source PNGs are preserved. The video renderer adds camera movement, timed UI layers, typing/deletion, captions and audio. This is a cinematic 3D look animated as a layered 2.5D composition; it is not rigged or lip-synced 3D character animation. The people and chat sessions are illustrative, not customer testimonials.

Exact prompts and saved asset paths are recorded in the delivery's `Artwork_Prompts.json`. Project reference paths use these local filenames and do not depend on the image tool's generated-images folder.
